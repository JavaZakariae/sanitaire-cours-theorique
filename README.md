# Sanitaire — cours théorique interactif

Version simplifiée et interactive du cours « Travaux pratiques en base du sanitaire — Cours de technologie » (TPBS CT 2026-2027).

- 5 chapitres expliqués simplement : vue d'ensemble, notices techniques, hydraulique (débit, pression, vitesse), tuyaux d'alimentation, tuyaux d'évacuation
- Schémas et outils interactifs : chemin de l'eau, pente, manomètre, vitesse dans un tuyau, effet Venturi, décodeur de tailles, usages autorisés
- Résumé express, flashcards, glossaire
- Plus de 100 QCM corrigés et expliqués, avec examen blanc de 20 questions

Ouvrir le cours : https://javazakariae.github.io/sanitaire-cours-theorique/

Tout tient dans `index.html` (aucune dépendance, aucun build).
